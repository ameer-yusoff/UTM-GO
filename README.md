# UTM-GO 🚌

> **Smart Campus Bus Shuttle Tracker & Navigation Web App for Universiti Teknologi Malaysia (UTM)**  
> Sesi Akademik 2026/2027

UTM-GO is a modern web application designed for UTM students, staff, and visitors to track campus shuttle buses in real-time, view official schedules and routes, and plan journeys across the Skudai campus.

---

## ✨ Features

- 🗺️ **Interactive Campus Map**: Powered by Leaflet with campus boundaries, bus stop markers, and route overlays.
- ⏱️ **Real-Time Shuttle Tracker**: Live simulated bus tracking based on official schedules and route geometries.
- 📅 **Official Schedule Viewer**: Comprehensive timetable by day and route, with Friday prayer breaks taken into account.
- 🧭 **Intelligent Trip Planner**: Select origin and destination bus stops to get the best route, estimated travel time, and next departure.
- 📱 **Mobile-First Responsive Design**: Optimized for smartphones with smooth bottom navigation and drawer panels.
- 🛠️ **Dev & Simulation Panel**: Test and simulate bus positions at any time of day.

---

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Maps**: [Leaflet](https://leafletjs.com/) & [React-Leaflet](https://react-leaflet.js.org/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/ameer-yusoff/UTM-GO.git
   cd UTM-GO
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
